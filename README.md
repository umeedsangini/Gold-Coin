# Gold Coin Miner

A simple Android mining game prototype. The miner animates automatically and awards 1 Gold Coin for each completed minute while the app is open. The app keeps the display awake. Coins are saved locally on the device.

## Build APK with GitHub Actions
1. Create a new GitHub repository.
2. Upload all files and folders in this project to the repository root.
3. Open the **Actions** tab and run **Build Gold Coin Miner APK** (or push to `main`).
4. Open the completed workflow run and download the `Gold-Coin-Miner-APK` artifact.
5. Extract the ZIP and install `app-debug.apk` on your Android phone.

This is a local demo wallet only; coins have no cash value and are not synced to a server.
